LumaGrader — third-party software used for RAW decoding
================================================================

This folder contains a WebAssembly build of LibRaw, loaded only when a RAW file is opened.

libraw-wasm 1.6.0 (JavaScript/WebAssembly bindings)
  https://github.com/ybouane/LibRaw-Wasm — ISC License

  Common Development and Distribution License v1.0 (CDDL-1.0).
  Source code: https://github.com/LibRaw/LibRaw

Little CMS (colour management, linked into the build)
  https://www.littlecms.com — MIT License

LibRaw is used as an unmodified, separately loaded library (libraw.wasm). You may replace
libraw.wasm / libraw.js / worker.js in this folder with your own build of the same
libraw-wasm version; build instructions are in the libraw-wasm repository above.
